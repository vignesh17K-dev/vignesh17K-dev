I'm **Vignesh K**, a software engineer in Bangalore. I build product-facing web and mobile apps — from auth and payments to realtime maps.

Lately I’ve been focused on **Eat Me**, a food-delivery app for iOS and Android: Expo / React Native on the client, Express + MongoDB on Vercel, with Supabase auth, Razorpay, Pusher, and live courier tracking.

#### 📌 Featured work

**Eat Me — food delivery (iOS & Android)**  
Browse menus, pay with Razorpay, track the courier live on the map.

- Client: [Food-native-app](https://github.com/vignesh17-k/Food-native-app) — Expo, React Native, TypeScript, Redux
- API: [food-app-backend](https://github.com/vignesh17-k/food-app-backend) — Express, MongoDB, Razorpay, Pusher, QStash, Vercel
- Auth: email, phone OTP, Google, forgot/reset password (Supabase)
- Orders: status stepper + live location on private Pusher channels

**Other projects**
